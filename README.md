# Cusezar - Conecta CX

Guion de atención telefónica y centro de conocimiento de Experiencia.

## Distribución

Abre o descarga [Conecta CX · Troncal](dist/Conecta_CX_Troncal.html). Es un HTML autocontenido: incluye estilos, scripts, imágenes y formatos PDF. Los enlaces a portales corporativos requieren acceso a esos servicios.

`dist/` es el nombre habitual de la carpeta de artefactos de distribución de producción. La entrega incluye guion, clasificación, orientación y guías; sin gestión de asesores.

La fuente de desarrollo se conserva por separado. Este repositorio contiene la entrega preparada para compartir.
